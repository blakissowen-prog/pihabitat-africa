# PiHabitat Africa
Plateforme immobilière au Burkina Faso - Achat de terrains titrés à Ouagadougou avec paiement Pi Network.

Live Demo: https://pihabitat-africa.netlify.app
Repo: blakissowen-prog/pihabitat-africa

Stack:
- HTML / CSS / JavaScript
- Pi Network SDK
- Netlify Functions

Fichiers:
- approve.js : approuve paiement Pi
- complete.js : complete paiement Pi
- index.html : site principal
